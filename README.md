# ClientPilot

ClientPilot is a lightweight CRM built for digital agencies to capture, organize, and manage incoming client inquiries.

## Features

- Responsive Landing Page
- Lead Capture Form
- Client-side Validation
- Server-side Data Storage
- Prisma ORM
- Supabase PostgreSQL
- Admin Dashboard
- Search Leads
- Update Lead Status

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Prisma ORM
- Supabase
- React Hook Form
- Zod
- Sonner

## Installation

```bash
npm install
npm run dev
```
